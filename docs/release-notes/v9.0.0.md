The first release of janook, an open-source implementation of the Animal Variant Classification
Guidelines (AVCG) — the published 2024 standard for deciding whether a genetic variant in an
animal causes disease.

## What this release does

- **Classifies a variant from an evidence file.** You record which variant it is and what you
  decided about each of the 23 criteria, with your reasons and citations; `janook classify`
  applies the guideline's decision process and shows its work — the rule that fired, the criteria
  that satisfied it, and both branches' answers.
- **All 23 AVCG criteria, encoded verbatim** from Table 4 of the publication and published for
  review, in the repository and via `janook explain`.
- **The full decision process of Table 6**: both branches always evaluated, and conflicting
  evidence honestly reported as uncertain rather than silently resolved.
- **Nine species out of the box** — the nine of the paper's cross-species check, cat first.
- **Spreadsheet input**: `janook classify --batch` takes one variant per TSV row.
- **A template to start from**: `janook init` prints an evidence file with every criterion
  explained.
- **Four output forms**: a terminal summary, a one-line `--brief`, machine-readable `--json`, and
  a `--report` Markdown document carrying every criterion, justification, and the provenance —
  tool version, guideline edition, species profile, input hash, date, operator.
- **Exit codes a script can rely on**: 0 answered (uncertain is an answer), 1 input rejected,
  2 command not understood, 3 janook's own bug.

## What this release deliberately omits

- **`janook validate` is not in yet.** It will run the guideline's published 53-variant feline
  truth set and reproduce the paper's accuracy figure. The per-variant criterion assignments it
  needs are not in the paper's supplementary material, and we have asked the guideline authors
  for them; `validate` ships in a minor release when that data is available.
- **No Bioconda package yet** — it is in progress. For now: download the archive below, unpack,
  and run `bin/janook` (Java 25 or later required).
- **No built-in PDF report** — the `--report` output is Markdown; `pandoc report.md -o report.pdf`
  converts it.

## Install

```
tar -xzf janook-9.0.0-dist.tar.gz
janook-9.0.0/bin/janook --version
```
